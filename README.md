# Hari Krishna Kumar - Portfolio

Personal portfolio website showcasing my work as a Freelance Developer & ML Engineer.

## Live Demo

🔗 [harikrishnakumar.github.io/resume](https://harikrishnakumar.github.io/resume/)

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 6** - Build tool
- **Tailwind CSS 4** - Styling
- **Motion (Framer Motion)** - Animations
- **Lucide React** - Icons

## Features

- Cinematic letter-block text animations
- Auto-cycling chapter showcase
- Sand-transition image effects
- Responsive design (mobile-first)
- Dark/light section contrast
- Smooth scroll animations

4. **Technical Trainer** - Guiding students at Yajurvedh
5. **Backend & Tools** - FastAPI, SQL, Git, Google Cloud

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Deployment

Auto-deploys to GitHub Pages on push to `main` branch via GitHub Actions.
